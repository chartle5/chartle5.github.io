Ora Your AI Assistant

About the app ▼

I attended the Microsoft AI Tour and learned how to use some new technologies such as Azure AI Foundry. Eager to experiment with model deployment and fine-tuning, the next day I built a study assistant web app that allows students to chat with an AI agent and upload lecture PDFs to generate concise, copy-pasteable notes and auto-generated quizzes. I used React + TypeScript (Vite) on the frontend, FastAPI on the backend, a fine-tuned Azure OpenAI (gpt-4o-mini) model for reasoning and summarization, and PyPDF for text extraction.

Caeprabank

About the app ▼

CaepraBank is a modern banking application currently under development. I built this app intending to explore cloud-native architecture focusing on mastering containerization using Podman/Docker and deploying application containers as images in Azure Container Registry (ACR). Future iterations will integrate AI models capable of analyzing PDFs of banking documents -- including insurance claim forms and credit loan applications -- to automate data extraction and reduce manual workload within the banking system.

Europe Travel Guide

About the app ▼

The Europe Travel Guide was an independant university project designed to let users conduct high-level research on European vaction destinations. As my first full-stack web application, it was built to implement the core principles of modern web architecture, including admin privileges, secure session management with JSON Web Tokens (JWTs), and encrypted client-server communication. The backend is powered by Node.js with Express.js as middleware, and the frontend uses Angular for an interactive user experience. A MongoDB database manages user and destination data, while a CSV file was used for data extraction and parsing.

Medlife

About the app ▼

Medlife is a mobile healthcare management application developed collaboratively for a university client project in partnership with a healthcare provider from India. The goal was to improve the efficiency of small-scale eye care clinics by transitioning from manual record-keeping to a digital patient management system. Built with React-Native for cross-platform compatibility, Medlife enables clinics to manage patient records, collect preliminary health information, and visualize patient data through an intuitive UI and dashboard.
